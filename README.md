# MenteSaudável - Site de Conscientização sobre Saúde Mental para Jovens

## 🎯 Objetivo

Um site informativo e acessível dedicado a conscientizar jovens sobre saúde mental, oferecendo recursos, informações e orientações sobre problemas psicológicos comuns.

## 📋 Funcionalidades Principais

✅ **Navegação Intuitiva** - Menu claro e fácil de usar

✅ **Tópicos Educativos** - Artigos sobre:
- Ansiedade
- Depressão
- Estresse
- Problemas com Sono
- Relacionamentos
- Autoestima

✅ **Recursos Úteis**
- Teste de Autoavaliação
- Exercícios de Relaxamento
- Biblioteca de Artigos
- Linhas de Ajuda

✅ **Seção de Emergência** - Contatos de profissionais e linhas de prevenção

✅ **Formulário de Contato** - Para dúvidas e sugestões

✅ **Design Responsivo** - Funciona em desktop, tablet e mobile

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização com gradientes e animações
- **JavaScript Vanilla** - Interatividade sem dependências

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/gabriell1411/site-de-conscientiza-o-.git
   cd site-de-conscientiza-o-
   ```

2. **Abra no navegador**
   - Abra o arquivo `index.html` diretamente no seu navegador
   - Ou use um servidor local (ex: Live Server no VS Code)

3. **Navegue pelo site**
   - Explore os tópicos educativos
   - Utilize os recursos disponíveis
   - Acesse as linhas de ajuda se necessário
